# Courtside College Basketball Accessible Beta 1

This beta adds a keyboard- and screen-reader-focused accessible mode to LH Games Courtside College Basketball.

## Install and start

1. Download `Courtside-Accessible-Beta-1.zip` from this release.
2. Extract the entire ZIP to a writable local folder such as `C:\Games\Courtside`.
   Do not run the game from inside the ZIP. Avoid `Program Files` and cloud-synchronized folders such as OneDrive.
3. Run `1 Install Team Data.cmd` once. An internet connection is required.
4. Run `2 Start Accessible Game.cmd` whenever you want to play.

The release also provides a SHA256 checksum file so testers can verify their download.

## Tested configuration

- Windows 11, 64-bit
- JAWS 2026, version 2026.2606.132.400

Older versions of JAWS are expected to work, but have not yet been formally tested. Windows 10 version 22H2, 64-bit receives best-effort support.

Windows 7, Windows 8, Windows 8.1, and 32-bit Windows are not supported.

## What to test

Please try complete games, including multi-word team selection, manual player selection, passing and narration, substitutions, timeouts, halftime, accessible box scores, and overtime. See `BETA TESTING AND FEEDBACK.txt` inside the package for the details to include in a report.

Report beta problems in the [GitHub issue tracker](https://github.com/rsh8091/jaws-accessible/issues).
