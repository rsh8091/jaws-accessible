# Accessibility help

This is a menu-driven game. Type a menu choice, then press Enter.

These are common navigation choices you will see or hear frequently:

- **1:** Continue or start play.
- **0:** Go back.
- **98:** Keep your current selection.
- **99:** Cancel.

Each menu explains what its numbered choices do.

Typed commands, such as back, are optional.

The game pauses at key points so you can review the text with your screen reader. Press Enter when prompted to continue.

**Press Enter to return to the main menu.**
