COURTSIDE COLLEGE BASKETBALL ACCESSIBLE - VERSION 1.0
October 27, 2026

ACCESSIBLE GAMEPLAY
This release adds an optional screen-reader-friendly interface around the
original basketball simulator. Start with "2 Start Accessible Game.cmd",
or run HELLO.exe --accessible. Starting HELLO.exe normally uses the
original graphical interface.

- Numbered menus for teams, rules, lineups, offense and defense.
- Complete regulation and overtime gameplay, with passing and shooting decisions.
- Accessible play-by-play, game clock and status reports.
- Substitutions, timeouts, halftime adjustments and intentional fouling.
- Coaching choices before overtime.
- Spoken player/team box scores and an HTML postgame box score.
- Back, Cancel and confirmation pauses at supported menus.
- Accessibility Help describing the numbered controls; typed commands are optional.
- Team-data installer with keep, reinstall and cancel choices and checksum checks.

This release focuses on single-game play. Accessible season, tournament and
schedule management are outside its scope. See KNOWN ISSUES.txt for existing
simulation defects, including free-throw shooter substitution.

UPSTREAM AND VALIDATION
Based on Jason Leonard's upstream main through a0e9407 (October 10).
The October 23 build passed all 18 gameplay test scripts, the source-level
intentional-foul regression, and both installer test scripts. Package checks
cover contents, launchers, checksum and offline team-data installation.
The tester completed a full game with RC5 and reported that it went fine.
Version 1.0 packages that same game executable with finalized release documents.

The upstream schedule-editor update has not been manually tested. Individual
screen-reader checklist items were not all separately confirmed by the
full-game report. See README FIRST.txt for platform details.
