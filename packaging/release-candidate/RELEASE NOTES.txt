RELEASE 1, CANDIDATE 4 (1.0-RC4)
October 15, 2026

SCOPE
Accessible single-game play: team and rule setup, numbered coaching menus,
passing and shooting decisions, substitutions, timeouts, halftime, overtime,
and accessible box scores. Season and tournament accessibility are outside
this release candidate's scope.

NEW SINCE RC3
- Missing team data opens a Windows information dialog that waits for OK.
  If the dialog cannot open, the console repeats the message and waits for Enter.
- Re-running the data installer offers 1 to keep, 2 to reinstall, or 99 to
  cancel. Blank and invalid input never authorize replacement.
- The installer verifies the archive against the pinned SHA-256 checksum
  before extraction and rejects unsupported team-data filenames before copying.
- The startup launcher uses the full Windows PowerShell path.
- Installation guidance stays in the README and installer, keeping in-game
  Accessibility Help focused on game controls.

PREVIOUS IMPROVEMENTS INCLUDED
- Coaching options before every overtime, plus an overtime practice launcher.
- Offense and defense confirmations pause for Enter during play.
- Shorter Accessibility Help.
- Halftime strategy changes, substitution navigation and final lineup announcements.
- Substitution bench-rest recovery and timeout-resume improvements.

VALIDATION AND LIMITATIONS
All 21 regression scripts passed on the October 15 build, covering game menus,
team/setup navigation, narration, strategy ownership, halftime, overtime,
substitutions and recovery, timeouts, intentional fouls, late-game choices,
box scores, pacing, repeat installation and installer security.
The human-versus-computer test's exit sequence was corrected after its spare
inputs opened Help; its gameplay assertions and clean-exit check then passed.
A fresh online installation also downloaded, verified and installed all 75
team-data sets. The known free-throw substitution defect was reconfirmed.

The tester completed RC3 gameplay testing. RC4 focuses on installation and
startup changes; hands-on screen-reader testing is still required.
The upstream baseline remains f504b55 (September 19), fetched on October 6,
with README PR #10. No further upstream engine merge is included in RC4.

See TESTING AND FEEDBACK.txt for the RC4 checklist and KNOWN ISSUES.txt for
the existing simulation defects, including free-throw shooter substitution.
Automated regressions do not replace listening to the actual screen reader.

This is a local candidate package. No GitHub release or release page has been
published as part of preparing it.
